# 🛡️ PatchGuard-Local

온디바이스(로컬) AI 기반 소스코드 보안 취약점 진단 및 시큐어 코딩 패치 도구 (WIP / 프로토타입 단계)

## 📌 주요 특징
- **Zero Data Leak**: 외부 API 전송 없이 로컬 경량 모델(Ollama)을 활용한 오프라인 분석
- **프로젝트 단위 진단**: 단일 파일 및 ZIP 프로젝트 압축 파일 지원
- **다국어 지원**: 한국어 / 영어 리포트 지원

## 🚀 실행 방법
1. **Ollama 실행 및 지원 모델 선택 (사양별 비교)**

   사용자 PC 환경과 그래픽카드(VRAM) 사양에 맞춰 적합한 모델을 선택하여 구동할 수 있습니다. (앱 구동 시 로컬에 설치된 모델 목록이 자동으로 감지됩니다.)

| 모델 이름 | 모델 용량 | 한글 지원 여부 | 추천 여부 | 특징 |
| :--- | :---: | :---: | :---: | :--- |
| **`qwen2.5-coder:7b`** *(기본값)* | 약 4.7 GB (권장 VRAM 6~8GB) | **완벽 지원** (상급) | **강력 추천 (기본 탑재)** | 코드 정적 분석 및 OWASP 결함 탐지율 최상, 한국어 진단 지침 완벽 준수 |
| **`qwen2.5-coder:1.5b`** | 약 1.0 GB (권장 RAM 4GB) | **지원** (양호) | **경량 추천 (저사양용)** | 내장 그래픽/노트북 환경 최적화, 경량화 환경에서 빠른 결함 탐지 가능 |
| **`deepseek-coder:6.7b`** | 약 3.8 GB (권장 VRAM 6GB) | **부분 지원** (보통) | **조건부 추천 (영문 권장)** | 코드 분석 성능은 우수하나 한국어 진단 요청 시 간헐적 영문 출력 발생 |
| **`codellama:7b`** | 약 3.8 GB (권장 VRAM 6GB) | **미흡** (기초) | **비추천** | 메타 코드 모델로 영어 프롬프트 위주 동작, 다국어 지침 처리 미흡 |
| **`llama3:8b`** | 약 4.7 GB (권장 VRAM 8GB) | **지원** (우수) | **비추천 (오탐 다수)** | 일반 자연어 챗 모델로 시큐어 코딩 전용이 아니며 취약점 분석 시 오탐(False Positive) 빈도 높음 |

```bash
   # [권장] 기본 보안 진단 모델 다운로드 및 실행
   ollama run qwen2.5-coder:7b

   # [저사양] 경량 모델 다운로드 및 실행
   ollama run qwen2.5-coder:1.5b
```


2. 필요 패키지 설치:
   ```bash
   pip install streamlit requests
   ```
   
3. 앱 실행:
   ```bash
   python -m streamlit run app.py
   ```
